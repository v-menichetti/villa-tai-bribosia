# Roadmap

## 1. Foundation — delivered

- [x] Next.js / React / TypeScript / Tailwind setup and npm lockfile
- [x] Approved design reference and shared palette / fonts
- [x] Initial responsive page structure and separate factual content
- [x] 2027 rates with explicitly unknown availability
- [x] Unit tests, lint, formatting, build and CI configuration
- [x] Codespaces configuration and contributor guidance

## 2. Photographic implementation

- [ ] Receive original property photos and confirm rights for regional imagery.
- [ ] Implement the selected pool hero, photo compositions and galleries faithfully.
- [ ] Add restrained reveals and transitions after the static layout is approved.
- [ ] Verify responsive crops, keyboard flow, contrast and reduced-motion behaviour.

## 3. Enquiry flow

- [ ] Confirm owner name and public contact details.
- [ ] Collect requested arrival/departure, adults/children, email and message.
- [ ] Add server-side validation, abuse protection and a transactional mail provider only when ready.
- [ ] Report actual delivery success/failure; never show fake sent states.
- [ ] Add appropriate privacy information and retention rules.
- [ ] Keep booking confirmation manual unless a separate booking system is requested.

## 4. Content sign-off

- [ ] Maximum guest capacity and exact bunk-bed / sofa-bed configuration.
- [ ] Status and price of 7–21 August 2027; actual availability elsewhere.
- [ ] Multiple-week discount terms, deposit, cleaning, possible tax/fees, cancellation and check-in/out.
- [ ] Wi-Fi, cooling, appliances, baby equipment, accessibility and parking vehicle count.
- [ ] Validate travel times from the actual address; do not publish the listing’s “20 minutes” as guaranteed summer travel time.

## 5. Launch

- [ ] Owner approves photos, text, contact and final design.
- [ ] Configure domain, production URL and hosting environment.
- [ ] Complete legal and privacy information for the actual operator.
- [ ] Verify contact end to end, mobile, accessibility, metadata and image performance.
- [ ] Enable indexing only after approval, then verify robots and sitemap.

## Later, only if needed

An owner editing interface, calendar synchronisation, multilingual content and online payments are separate features. No database or paid service is required for the initial brochure website.
